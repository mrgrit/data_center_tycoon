# Data Center Tycoon

데이터센터를 짓고 굴리는 브라우저 경영 시뮬레이션.
빌드 도구도 의존성도 없다. `index.html` 을 열면 그게 전부다.

## 이 게임이 다루는 것

수치가 전부 실제 단위다. kW, ℃, kWh, PUE, 원. 화면의 숫자를 그대로 현실의
숫자로 읽을 수 있어야 교보재를 겸할 수 있기 때문이다.

**모든 전기는 결국 열이 된다.** 서버가 쓴 kW 는 그대로 kW 의 열이고, 그 열을
빼려면 또 전기가 든다. 이 되먹임이 게임의 긴장 전체를 만든다 — 매출을 늘리려고
부하를 올리면 열이 오르고, 열을 빼려니 전기가 늘고, 전기가 늘면 전력 경로의
어느 지점이 먼저 찬다.

**용량은 총량이 아니라 경로의 각 지점에서 따로 성립해야 한다.**
수전 → 변압기 → UPS → 랙. 총합이 남아도 한 지점이 모자라면 거기서 끊긴다.
실무에서 증설 사고가 나는 자리가 정확히 여기다.

## 하는 일

| | |
|---|---|
| **짓는다** | 랙(표준·고밀도·GPU)과 냉각(CRAC·인로우·CDU)을 바닥에 놓는다 |
| **늘린다** | 수전·변압기·UPS·발전기·냉동기·이코노마이저는 용량으로 산다 |
| **받는다** | 계약은 kW 와 SLA 를 요구한다. 평판이 오르면 단가가 다른 계약이 온다 |
| **버틴다** | 냉각 고장·정전·폭염·DDoS·누수·랜섬웨어. 모든 선택지가 무언가를 지불한다 |
| **읽는다** | 손익 탭에 매출·전기·고정비·사고 대응비·위약금·투자가 갈라져 나온다 |

조작은 넷뿐이다. 클릭=설치 · 우클릭=철거 · 휠=확대 · Shift+드래그=이동 · Space=일시정지.

## 게임이 가르치는 것

- **PUE 는 냉각 설계의 결과다.** 인로우(COP 4.2)와 CRAC(COP 3.0)의 차이가
  전기요금으로 매달 돌아온다. 외기가 더울수록 COP 가 떨어져 여름 요금이 튄다.
- **UPS 는 초 단위를 메우는 장비다.** 시간 단위는 발전기의 몫이다.
  발전기 없이 99.9% 를 지킬 수 없다는 것을 요금 고지서가 알려 준다.
- **N+1 은 취향이 아니다.** 냉각기든 냉동기든 한 대 고장에 방이 삶기면
  그 달 SLA 는 끝난다. 여유를 남기는 비용과 안 남기는 비용을 저울에 올린다.
- **온도가 정상이라는 사실이 안전하다는 뜻이 아니다.** CDU 누수는 냉각 문제이기
  전에 전기 안전 문제다.
- **랙에 자리가 있다고 받을 수 있는 것이 아니다.** 열을 뺄 수 있어야 받는 것이다.

## 구조

```
index.html          화면 뼈대
css/style.css       어두운 관제실 톤
js/catalog.js       장비·계약·인력 — 모든 수치가 여기 모여 있다
js/sim.js           물리·경제 (열수지, 전력 경로, SLA, 정산)
js/events.js        사고와 선택지
js/world.js         상태·행동·저장
js/render.js        아이소메트릭 캔버스 렌더러
js/ui.js            패널 갱신
js/main.js          루프와 입력
```

저장은 브라우저 `localStorage` 에 자동으로 된다(게임 내 하루에 한 번).

## 만들면서 잡은 것들

화면만 보고 만들었으면 못 잡았을 것들이다. 모형을 Node 로 떼어내 2년치를
돌려 보고 나서야 보였다.

- **냉각 전력을 설치 용량 기준으로 계산하고 있었다.** 48kW 짜리 전산실에
  155kW 냉각을 붙였다는 이유만으로 PUE 가 2.1 이 나왔다. 여유를 갖는 것이
  곧 벌점이 되는 셈이라 게임으로도 틀렸고, 실제 장비는 부하에 따라 출력을
  조절하므로 물리적으로도 틀렸다.
- **DDoS 가 계약 부하를 1.25배씩 영구히 곱하고 있었다.** 복구가 선택지에만
  있어서 안 고르면 누적된다. 2년에 55번이면 360만 배가 되고, 위약금이
  2,514억까지 갔다.
- **냉동기 고장이 대수와 무관하게 냉수를 전부 끊고 있었다.** 3대를 사도
  1대 고장에 전부 죽는다. 이 게임에서 가장 중요한 교훈을 배우는 것이
  구조적으로 불가능했다 — 투자로 막을 수 없는 사고는 벌이지 교보재가 아니다.
- **SLA 를 계약 만료 때만 따졌다.** 계약이 8~18개월이라, 방이 75℃ 로 삶기고
  전 계약이 죽어 있어도 몇 달 동안 아무 신호가 없었다. 늦은 벌은 배움이 되지
  않는다. 월 단위 정산으로 바꿨다.
- **계약 단가가 전기요금보다 낮았다.** 1kW 를 한 달 켜 두면 약 119,000원이고
  PUE 1.5 면 178,000원인데 단가를 95,000~130,000원으로 잡아 놨었다.
  무엇을 해도 망하는 게임이었다.
- **시뮬레이션을 rAF 에 묶어 놨다.** 탭이 가려지면 데이터센터가 같이 멈춘다.
  그리고 화면 수치도 rAF 에만 걸려 있어서, 값이 실제 상태와 갈라졌다.

### "무조건 망하는 게임 아니냐" — 두 번째 균형 조정

첫 판을 올린 뒤 받은 지적이다. 3년치를 다시 돌려 보니 맞는 말이었고,
원인은 균형이 아니라 **보이지 않는 지출**과 **닫힌 회복 경로**였다.

- **사고 대응비가 장부에 안 잡혔다.** 3년 시뮬레이션에서 매출·전기·고정비·
  투자를 다 더해도 44억이 비었는데, 그게 전부 사고 대응비였다. 화면에는
  손익표 자체가 없었으므로 플레이어는 **돈이 어디로 갔는지 알 방법이 없었다.**
  경영 시뮬레이션에서 손익표는 편의 기능이 아니라 본체다.
- **그 대응비가 고정값이었다.** CRAC 한 대 외주 출동 1,200만원은 50kW 시설
  (월 영업이익 375만원)에는 세 달치 이익이고 500kW 시설에는 푼돈이다.
  합쳐서 **월 6,714만원** — 잘 굴린 시설 영업이익의 71% — 이 나갔다.
  이제 월매출에 연동한다. 작을 땐 작게, 클 땐 크게, 판단의 무게는 같게.
- **사고가 3일에 한 번 왔다.** 사고 하나가 모달을 띄우고 게임을 멈추는데
  3일에 1건이면 운영이 아니라 소방이다. 초반 2주, 대형 6일에 1건으로 낮췄다.
- **용량을 한 번 넘기면 회복이 불가능했다.** 어느 지점이든 초과하면 전체를
  정전시켰다 — 매출은 0 인데 위약금은 계속 나가고 현금이 없어 증설도 못 한다.
  한 번 넘긴 판이 -38억까지 갔다. 실제 시설은 그렇게 동작하지 않는다.
  이제 **단가가 높은 계약부터 지키고 낮은 것부터 끊는다.** 증설하면 저절로
  돌아온다. 벌은 남되 되돌릴 수 있어야 배움이 된다.
- **평판이 계약 만료 때만 올랐다.** 계약이 6~36개월이라 3년을 완벽하게
  운영해도 20 → 40 이었고, 스트리밍(40)·AI 추론(55)·AI 학습(70)은 사실상
  도달 불가였다. GPU 랙도 CDU 도 액랭도 **존재만 하고 평생 못 보는 콘텐츠**였다.
  이제 매달 운영 실적으로 평판이 움직인다.
- **UPS 가 냉각 부하까지 받치고 있었다.** 총 투자 14.3억 중 3.2억이 UPS 였다.
  비싼 데다 틀린 모형이다 — 실제로 냉각기는 UPS 뒤가 아니라 발전기 뒤에 붙는다.
- **현금만 보여 줬다.** 매출이 2,077만 → 8,869만으로 4.3배가 되는 동안 현금은
  계속 1~2억이었다. 증설이 전부 손실로 보인다. 순자산과 월 손익을 띄웠다.
- **빈 방에서 시작했다.** 로그는 "데이터센터를 인수했다"는데 화면은 빈 방이라
  말과 그림도 안 맞았고, 돈이 들어오기까지 게임 내 한 달이 걸렸다.
  이제 작게라도 이미 도는 시설을 물려받는다.
- **시계가 느렸다.** 게임분당 260ms 는 16× 를 켜도 한 달에 실시간 11.7분이다.
  90ms 로 줄이고 60× 를 더했다 — 최고 배속에서 한 달이 약 65초.
- **사고를 처리하면 배속이 1× 로 떨어졌다.** 사고는 판단을 요구하는 것이지
  조작을 요구하는 게 아니다. 이제 보던 배속으로 돌아온다.

조정 뒤 3년(잘 지은 판, 실측): 순자산 14.3억 → 24.7억, IT 부하 0 → 513kW,
월매출 2,290만 → 2.29억, 위약금 0, 정전 0분. 영업이익률 42~53%, 투자 회수
17~18개월. 단가는 이미 실제 코로케이션의 2~3배이고 투자비는 실제의 1/3이라
**더 부풀리면 교보재로서 거짓말이 된다** — 그래서 체감 속도는 단가가 아니라
시계와 지표로 풀었다.
